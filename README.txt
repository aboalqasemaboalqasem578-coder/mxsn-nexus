MXSN Nexus v3

نسخة متجر متكاملة بواجهة + Backend Node.js في مشروع واحد.

تشغيل محليًا:
1) ثبّت Node.js 18 أو أحدث.
2) افتح مجلد المشروع.
3) نفّذ: npm install
4) انسخ .env.example إلى .env وعدّل JWT_SECRET و ADMIN_PASSWORD.
5) نفّذ: npm start
6) افتح: http://localhost:3000
7) لوحة الإدارة: http://localhost:3000/admin.html

المزايا:
- الطلبات محفوظة على الخادم، وليس localStorage.
- لوحة إدارة منفصلة ومحمية بتوكن JWT.
- إضافة/تعديل/حذف المنتجات.
- رفع ملف المنتج من لوحة الإدارة.
- إعدادات المتجر والصيانة.
- إعداد وسيلة الدفع وتعليماتها.
- اعتماد/رفض/استرداد الطلبات.
- رابط تسليم محمي بعد اعتماد الطلب.
- متابعة الطلب من جهة العميل.
- مشاركة المنتج عبر Web Share أو نسخ الرابط عند عدم توفرها.

مهم:
- الدفع اليدوي لا يتم التحقق منه تلقائيًا. الإدارة تتحقق من التحويل ثم تضغط «تم البيع».
- استرداد الأموال فعليًا يتم يدويًا؛ النظام يسجل حالة «تم الاسترداد» فقط.
- قبل الإنتاج غيّر ADMIN_PASSWORD وJWT_SECRET ولا تضع الأسرار في GitHub.
- هذا الإصدار يستخدم ملف JSON كقاعدة بيانات بسيطة. عند زيادة المبيعات يفضل نقل البيانات إلى PostgreSQL أو قاعدة بيانات مُدارة.
